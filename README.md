# success — Personal Portfolio

Modern dark portfolio for success (Oko300).

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Lucide icons

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and deploy on Vercel (zero config).
